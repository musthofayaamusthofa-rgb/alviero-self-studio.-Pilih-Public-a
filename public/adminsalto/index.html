Panduan & Sinkronisasi ke Web Internet

Kirim seluruh perubahan background, jam slot, dan data studio langsung ke website internet Anda di Vercel.

🌐 Alur Kerja Sangat Aman & Mudah:

  1. Edit Data: Ubah background, jam slot, atau promo sesuai kebutuhan Anda.
  2. Uji Lokal: Klik tombol 'Simpan ke Web Lokal' dan cek di 'Pratinjau Web (3000)'.
  3. Publikasikan: Klik tombol 'Publikasikan ke Web Internet'. Sistem otomatis melakukan upload ke GitHub.
  4. Live: Server Vercel otomatis mengupdate website di internet dalam waktu ~30-60 detik.
